<h1>Analicemos ¿Qué ocurre en cada caso presentado anteriormente con los operadores y porqué JS me permite esto?</h1>
<h2>Porque está diseñado para ser flexible. Por ejemplo, podés usar cosas como x *= 3 para multiplicar y guardar el resultado en la misma 
  variable, o x ??= 10 para asignar un valor solo si x no tiene nada. También te deja comparar valores con === o !=, incluso entre distintos tipos. 
  Todo esto ayuda a escribir menos código y hacerlo más claro.</h2>

<h1>Analicemos ¿El comportamiento de los flujos de control es similar a otros lenguajes y ambientes de desarrollo?</h1>
<h2>Sí, bastante. Las estructuras como if, for, while o switch se usan igual que en lenguajes como Java o Python. 
Además, JavaScript tiene métodos como map, filter o forEach que te permiten recorrer datos sin escribir bucles largos.</h2>
